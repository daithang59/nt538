\section{Phụ lục: Mẫu đo hiệu năng}
\label{sec:appendix-benchmark}

Phần này là gợi ý cách tổ chức đo thời gian. Nhóm có thể thay bằng script thực tế đã dùng.

\begin{lstlisting}[caption={Mẫu đo thời gian một hàm MAIN}]
from time import perf_counter

def measure(func, path, repeat=3):
    times = []
    last_result = None
    for _ in range(repeat):
        start = perf_counter()
        last_result = func(path)
        end = perf_counter()
        times.append(end - start)
    return sum(times) / len(times), last_result
\end{lstlisting}

\section{Phụ lục: Mẫu phiên bản tuần tự tham chiếu}
\label{sec:appendix-sequential}

Phiên bản tuần tự chỉ dùng để đo so sánh trong báo cáo, không nộp lên hệ thống chấm. Khi trình bày trong báo cáo, nhóm cần mô tả ngắn gọn phiên bản tuần tự tương ứng thay vì đưa toàn bộ mã nguồn nếu phần hiện thực quá dài.

\end{table}
