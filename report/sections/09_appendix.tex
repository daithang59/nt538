\section{Phụ lục: Mẫu đo hiệu năng}
\label{sec:appendix-benchmark}

Phần này trình bày một mẫu đo thời gian tham khảo. Khi hoàn thiện báo cáo, nhóm cần thay thế hoặc đối chiếu với script đo thực tế đã sử dụng để bảo đảm số liệu có thể kiểm chứng.

\begin{lstlisting}[caption={Mẫu đo thời gian một hàm MAIN}]
from time import perf_counter

def measure(func, path, repeat=3):
    times = []
    last_result = None
    for _ in range(repeat):
        start = perf_counter()
        last_result = func(path)
        end = perf_counter()
        times.append(end - start)
    return sum(times) / len(times), last_result
\end{lstlisting}
